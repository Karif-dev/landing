# Лендинг Кирилла

Тёмный анимированный лендинг с 3D-сценой: «Лендинг под ключ — 15 000 ₽».
Адаптивный, без сборки: один файл `index.html`.

- `index.html` — сам сайт (десктоп и телефон)
- `design/` — исходные макеты из редактора дизайна

Перед публикацией замените заглушки в блоке контактов на свои (Telegram, почта, телефон).
